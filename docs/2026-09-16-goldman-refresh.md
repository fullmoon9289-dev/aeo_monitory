# 골드만 대시보드 통일 및 공개 웹 재진단

## 요청 범위

- 사용자의 명시적인 요청에 따라 골드만 화면을 위드유의 메뉴·카드·배치에 맞췄습니다.
- 위드유의 화면과 병원별 데이터·발행 일정은 보존했습니다. AI 예시 수치를 골드만 실적으로 복사하지 않았습니다.
- 골드만 공식 도메인은 `https://www.gold-man.com/`입니다. 이 작업은 메디앤서를 수정한 것이며 병원 홈페이지를 수정한 작업이 아닙니다.

## 관찰 시점과 범위

- 직접 HTTP 조회: 2026-09-15 23:53 KST. UI 정리일과 관찰일을 구분합니다.
- HTML 표본 10개 및 robots.txt·사이트맵 설정 4개를 확인했습니다.
- 원문 페이지 목록과 기술 관찰은 `data/goldman-audit.json`, 검토 항목은 `data/goldman-findings.ts`에 보관합니다.
- 검색 엔진이 보관한 과거 텍스트와 현재 서버 응답이 다를 때 이번 공개 웹 진단에는 현재 서버 응답을 사용했습니다.
- 표본 HTML의 정상 응답·설명 태그·canonical·JSON-LD 존재는 확인됐으나 색인 완료나 AI 인용을 의미하지 않습니다. 동적 상세 화면과 임상·광고 적합성은 별도 확인 대상입니다.

## 이전 진단에서 현재 결과로 교체한 항목

- 확인한 페이지들의 의료진 수 표기는 11명으로 일치합니다. 실제 재직 현황을 검증한 것은 아닙니다.
- robots.txt에 사이트맵 인덱스와 두 사이트맵이 안내돼 있습니다.
- 사이트맵 내부의 중복 URL은 재조회에서 발견되지 않았습니다. 일반 사이트맵 70개, 의료정보 사이트맵 106개입니다.
- 요로결석 페이지의 현재 서버 제목은 요로결석을 설명합니다. 오래된 검색 캐시의 제목을 현행 오류로 보고하지 않습니다.
- 위 변화가 메디앤서의 작업으로 발생했다고 판단하지 않습니다.

## 현재 권장 순서

1. 수술 안내·의료정보 문서·비급여 안내의 비용 범위, 포함 항목과 적용일을 병원에서 대조합니다.
2. 의료진이 치료 효과·위험의 단정적 설명과 용어를 검토합니다.
3. 야간 서비스의 실제 지점·시간·가능 처치를 확인하고 검색용 HTML에도 핵심 안내가 있는지 점검합니다.
4. 검색어별로 기존 질문형 문서를 찾아 중복 발행보다 보완을 우선합니다.

## 데이터와 기능 경계

- 저장된 Search Console CSV는 기존 API를 통해 표시합니다. 원본 검색어·세부 실적·인증 정보는 이 문서나 Git에 추가하지 않습니다.
- 자료의 기간과 가져온 행 수를 지표 옆에 명시합니다. 행 합계를 전체 실적으로 표시하거나 질문별 자료를 날짜별 추이로 재구성하지 않습니다.
- Search Console 계정 직접 연결, AI 답변·인용·추천 방문 수집은 여전히 미연결입니다. 관련 카드·그래프는 미측정 상태입니다.
- 질문 자료 갱신 실패 시 온보딩에 오류를 표시하고, 이전 질문 자료를 완료 상태로 계산하지 않습니다.
- 골드만 콘텐츠 스튜디오는 질문 기획과 일정 저장 단계입니다. 전체 원고, 검수 승인, CMS 자동 게시 완료를 주장하지 않습니다.
- 보고서 화면은 5장 구성의 인쇄/PDF 저장 기능을 사용합니다.

## 검증

- 기존 검색 CSV·질문 최신화·병원 분리·일정 저장 테스트를 유지합니다.
- 합성 자료만 사용한 골드만 화면 렌더 테스트를 추가했습니다.
- 실제 브라우저 자동 확인은 현재 로컬 도구 실행 오류로 완료하지 못했습니다. PDF 인쇄 결과의 실제 페이지 배치는 별도 확인이 필요합니다.
- 운영 DB·스키마·기존 검색 자료·발행 일정에는 변경을 수행하지 않았습니다.
