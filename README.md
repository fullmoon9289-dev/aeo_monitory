# MediAnswer

병원의 공개 홈페이지 정보와 검색 성과를 검토하고, 환자 질문에 맞는 콘텐츠 개선과 발행 계획을 관리하는 AEO 워크스페이스입니다.

운영 사이트: [MediAnswer](https://mediaanswer-aeo.fullmoon9289.chatgpt.site/)

## 현재 데이터 상태

2026-09-11 확인 기준입니다. **실제 자료, 공개 웹 표본 진단, 성과 예시를 구분해야 합니다.**

| 항목 | 위드유 의원·한의원 | 골드만 비뇨의학과 |
|---|---|---|
| 홈페이지 정보 | 공식 홈페이지 공개 정보를 정리한 자료 | 공개 HTML 7개와 수집 설정 파일 3개를 확인한 표본 진단 |
| 공개 검색 표본 | 검색 질문 5개에 대한 기존 관찰 기록 | 서치콘솔 검색 자료와 별도로 홈페이지 표본 진단을 보관 |
| 서치콘솔 실제 자료 | 아직 가져온 자료 없음 | 사용자 제공 내보내기 분석 완료, 검색어 CSV 저장 완료 |
| 실제 AI 언급·인용률 | 미측정. AI 노출 성과 화면은 DEMO | 미측정 |

CSV 업로드는 선택한 병원의 검색 자료를 저장하고 해당 행의 지표를 계산합니다. 기존 진단 보고서 전체를 자동으로 다시 작성하거나 AI 답변을 실측하는 기능은 아닙니다. 두 병원의 진단이 모두 완료됐다고 설명하지 않습니다.

전체 작업 경과, 근거 위치, 검증 내역, 남은 작업은 [작업 기록 및 인수인계](docs/2026-09-11-handoff.md)에 정리했습니다.

## 현재 구현된 기능

- 위드유 디자인을 기준으로 통일한 공통 왼쪽 메뉴·상단 바·카드 화면
- 위드유·골드만 병원 선택과 병원별 자료·일정 분리
- 골드만 대시보드의 실제 CSV 지표·상위 클릭 자료·진단 진행 상태
- 공식 홈페이지 정보와 공개 웹 표본 진단 보고서
- 환자 질문 지도와 콘텐츠 개선 기회 정리
- 의료진 검토를 전제로 한 콘텐츠 초안·발행 계획 관리
- 병원별 서치콘솔 검색어 또는 페이지 CSV 가져오기와 저장
- AI 언급·인용·추천 방문 성과를 설명하는 예시 화면
- 고객 설명용 [홍보 문안](docs/marketing/MediAnswer_AEO_홍보문안.md)

발행 계획 저장은 외부 홈페이지·티스토리에 실제 글을 발행한 것을 의미하지 않습니다. 서치콘솔 계정 직접 연결과 실제 AI 답변 모니터링은 아직 제공하지 않습니다.

## 데이터 보관

- 실제 업로드한 검색 자료와 발행 일정은 운영 사이트의 데이터베이스에 저장됩니다.
- 비공개 검색 원본, 세부 실적 보고서, 로컬 검증 자료는 Git에서 제외된 `work/`, `outputs/`에 보관합니다.
- Git 저장소에는 소스와 공개 가능한 작업 문서를 보관합니다. Git push만으로 운영 데이터베이스가 백업되거나 사이트가 다시 배포되지는 않습니다.
- 인증 토큰, DNS 소유권 확인 값, 계정 정보는 작업 문서나 저장소에 기록하지 않습니다.
