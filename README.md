# MediAnswer

병원이 AI 검색에서 얼마나 잘 추천되는지 모니터링하고, 환자 질문 여정에서 성장 기회를 찾아 의료 검토가 포함된 콘텐츠 발행까지 연결하는 AEO 운영 플랫폼입니다.

## 현재 구현된 기능

- 병원 AEO 커맨드 센터와 핵심 성과 지표
- 증상 탐색부터 병원 선택까지의 환자 질문 지도
- 노출 격차, 예약 의도, 의료 근거를 반영한 기회 점수
- 의료 신뢰도 체크가 포함된 콘텐츠 스튜디오
- 질문별 AI 답변, 브랜드 언급, 인용, 경쟁 병원 모니터링
- 반응형 모바일 사이드바와 인터랙티브 프로토타입

## 로컬 실행

```bash
pnpm install
pnpm dev
```

현재 화면의 병원 및 성과 데이터는 제품 경험 검증을 위한 샘플 데이터입니다.
